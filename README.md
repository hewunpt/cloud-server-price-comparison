## 三、低价套餐的真实限制，主要在三处

便宜套餐的坑集中在月流量包、首单资格和带宽换算这三件事上，跟 CPU 关系不大。买之前把这三项对一遍，比盯着“几核几 G”有用。

月流量是流量包，不是不限量。200G、300G、500G 这些数字看着大，一个日均千次访问的文字博客一个月也用不完 300G；换成图片站、资源下载或视频，300G 可能几天就见底。腾讯云轻量走的是流量包模式，而阿里云 99 元档给的是 3M 带宽不限流量，做下载类业务那边的规则更省心。

首单资格只能用一次。38 元、68 元、1.3 折的 99 元、450 元这几档都标着“产品首单限 1 个”，同一账号用掉就没有了。先买小配置想再升一台，第二台按原价算。配置宁可选大一点，也别指望后面补首单。

带宽要换算成下载速度看。1Mbps 理论下载速度约 128KB/s，3Mbps 大约 384KB/s。3M 挂 WordPress，一个几百 KB 的页面一秒多能打开；拿去分发 100MB 的文件，就得等上几分钟。所以 38 元档的 4核4G 适合跑 Docker、Node.js、编译测试这类吃 CPU 不吃流量的活；要对外提供下载，带宽和流量比核数重要得多。
